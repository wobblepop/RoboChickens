Exploration Cycle Overview

Each robot independently runs a 4-phase cycle every simulation tick
Step 1
ARRIVING
Reach node, snap position, drift correct
→
Step 2
SCANNING
360° feature detection, node/edge creation
→
Step 3
CHOOSING
Pick next edge by exploration priority
→
Step 4
TRAVELING
Drive to destination, collect corridor data
Loops back to ARRIVING on reach · Wall-stop and stuck recovery also restart from ARRIVING

Robot Agent — Main Exploration Loop

src/robot/robot-agent.ts

processTick(lidar, odometry) → MotorCommand Main loop — called every simulation tick
-- Called once per simulation tick with fresh LiDAR + odometry --
tickCount++
if first tick (not initialized):
initialize SLAM engine
set pose to exact origin (0, 0, 0)
-- Do NOT run processSensorData on tick 1
-- Particle noise would drift the starting pose away from origin
call doArriving(lidar, origin_pose)
return command
-- Normal ticks --
slamResult = SLAM.processSensorData(odometry, lidar)
pose = slamResult.pose
-- Track trail (breadcrumb positions for visualization) --
if moved > 0.3m since last trail point:
append pose to trail (max 150 points)
if phase is TRAVELING:
accumulate distance from last pose
every 20 ticks: run loop closure check, apply small correction if found
every 0.3m: collect corridor scan sample (for retroactive junction detection)
switch on phase:
ARRIVING → doArriving(lidar, pose)
SCANNING → doScanning(lidar, pose)
CHOOSING → doChoosing(lidar, pose)
TRAVELING → doTraveling(lidar, pose)
return motor command
+
Step 1 doArriving(scan, pose) → MotorCommand Arrive at target node, initialize SLAM data, correct drift
-- If this is the very first node, create it --
if no currentNode:
create starting feature at robot position
try createNode(feature, scan) -- runs +/-20 deg clearance adjustment
if rejected (tight start spot):
fallback: createNodeAtPosition(pose, Junction) -- no clearance check
set currentNode to the new node
create initial SLAM node map
-- Mark node as explored --
isFirstExploration = node was not previously explored
markNodeExplored(currentNode, robotId, timestamp)
-- Snap node to robot's actual position (first visit only) --
if isFirstExploration:
node.position = robot's actual pose
-- Push away from walls in cardinal directions --
for each cardinal direction (N, S, E, W):
find nearest wall via LiDAR in that direction
if wall < 0.3m away:
push node 80% of the gap away from wall
apply push only if destination cell is free in SLAM grid
-- Drift correction: compare fresh SLAM grid against stored node map --
if node has been visited before (stored map exists):
correction = computeMapCorrelation(current SLAM grid, stored node map)
if correction confidence > 0.2 and shift > 0.05m:
adjust node position by correction offset
-- Propagate drift correction to connected unexplored nodes --
for each unexplored neighbor (BFS, decay by distance):
shift neighbor position proportionally
-- Capture SLAM data --
if node map exists: update it with current SLAM grid
else: create new node map from current SLAM data
-- Pose refinement via correlative scan matching --
if tickCount > 50 and exploredNodes > 2:
SLAM.refinePoseAtNode(scan)
Design note Scan matching is DISABLED during travel. It only runs here, at node arrivals, to avoid compounding drift corrections while the robot is moving between nodes.
scanTicksRemaining = 5
transition to SCANNING
return stop()
+
Step 2 doScanning(scan, pose) → MotorCommand 360-degree scan, feature detection, node/edge creation
-- Wait 5 ticks for SLAM grid to accumulate data --
scanTicksRemaining--
if scanTicksRemaining > 0: return stop()
-- Run full 360-degree feature detection --
features = featureDetector.detectFromScan(scan, pose)
for each detected feature:
skip if distance < 0.5m -- too close to robot
skip if distance > 85% of scan range -- too far, unreliable
skip if position is occupied in SLAM grid
skip if no line of sight (checkLineOfSight returns clear=false)
-- Check for nearby existing node --
nearest = graph.findNearestNode(feature.position)
if nearest exists within minNodeSeparation:
-- Connect to existing node instead of creating a new one --
if no edge exists between currentNode and nearest:
create edge to nearest node
strengthen nearest node's confidence
continue
-- Create new node + edge atomically --
newNode = createNode(feature, scan)
if node created:
edge = graph.createEdge(currentNode, newNode, distance, bearing)
if edge creation fails:
remove the node -- atomic: no orphan nodes
Invariant: Atomic Node+Edge Creation Nodes are never created without a connecting edge. If edge creation fails after node creation, the node is immediately removed. This prevents orphan nodes that would confuse exploration.
-- Update exit count on current node --
currentNode.exit_count = max(edge_count, distant_feature_count)
-- Step 3: Connect to visible existing nodes --
call identifyVisibleEdges(scan, pose)
-- Detect side passages (perpendicular openings in corridors) --
call detectSidePassages(scan, pose)
-- Revalidate existing edges --
for each node in scan radius:
if direct LOS exists: add to visibleSet
call graph.revalidateEdgesFromNode(currentNode, visibleSet, timestamp)
-- Periodic maintenance (every 100 ticks) --
if tickCount % 100 == 0:
graph.applyFreshnessDecay(timestamp)
graph.pruneDeadEntities()
run validation pipeline (consistency engine)
attempt merge alignment with other robots (every 50 ticks)
transition to CHOOSING
return stop()
+
Step 2b identifyVisibleEdges(scan, pose) Connect to visible existing nodes via direct LOS
nodesInRange = all nodes within scan radius, sorted by distance
for each candidate node (nearest first):
skip if already connected to currentNode
skip if distance < 1.0m -- too close
skip if angularly occluded -- within 15 deg of an already-connected node
-- Use DIRECT ray only -- no +/-20 deg search --
if hasDirectLineOfSight(scan, pose, node.position, distance):
create edge(currentNode, candidate, distance, bearing)
edgesCreated++
record angle (for occlusion filter)
stop after 6 edges created
Critical Distinction: Edge LOS vs Node Placement LOS Edge creation uses hasDirectLineOfSight (single ray, no angular search). An edge is a straight line from A to B — if the direct ray can't see B, the straight-line edge would go through a wall.

Node placement uses checkLineOfSight (+/-20 deg search) to find the best wall clearance angle. This distinction was the source of many bugs during development.
+
Step 3 doChoosing(scan, pose) → MotorCommand Pick next edge to travel using exploration priority
-- Exploration priority (highest to lowest) --
0
Manual path queue — if user clicked a target, consume next hop. Recompute via BFS if edge is blocked.
1
BFS path to any unexplored node — find first edge on shortest path toward the nearest unexplored node in the entire graph.
2
Nearest untraveled edge — edges that have been created (visibility confirmed) but never physically traversed.
3
Adjacent node with most unmapped edges — prefer neighbors that have the most outgoing untraveled edges.
4
Random edge — last resort among graph edges.
F
Grid frontier detection — if no unexplored graph nodes remain, scan the SLAM occupancy grid for free cells adjacent to unknown cells. Serves as a fallback when the topological graph has been fully explored but territory remains unmapped.
if no edges and no frontiers found:
set scanTicksRemaining = 20 -- retry after waiting
transition to SCANNING
otherwise:
set targetNode, targetPosition, activeEdge
beginTravel(pose, timestamp)
transition to TRAVELING
return stop() -- actual driving starts next tick
+
Step 4 doTraveling(scan, pose) → MotorCommand Drive to destination, detect stuck and wall-stop conditions
if no target position: transition to ARRIVING
-- Check wall-stop condition --
if checkWallStop(scan, pose, target) triggers:
return stop() -- wall-stop creates a dead-end node and transitions to ARRIVING
distToTarget = distance(pose, targetPosition)
-- Arrival check --
if distToTarget < 0.5m:
completeTravel(scan, pose)
analyzeCorridorOnArrival(timestamp)
transition to ARRIVING
return stop()
-- Stuck check (2x normal threshold) --
if ticks in travel > 2x stuckThreshold (120 ticks):
call handleStuck(scan, pose) -- creates node, transitions to ARRIVING
-- Normal driving --
return motor.driveToward(targetPosition, pose, scan, timestamp)
+
createNode(feature, scan) → NetworkNode | null Create a node with clearance adjustment and ring wall check
-- Pre-check: reject if target position is inside a wall --
if SLAM.isPositionOccupied(feature.position): return null
-- +/-10 deg clearance adjustment --
if last scan available and distance > 0.5m:
los = checkLineOfSight(lastScan, pose, feature.position)
if clear and bestAngle differs from direct angle:
-- Shift node position toward the angle with best wall clearance --
lateralShift = distance * sin(angleDifference)
cap lateral shift to 0.5m maximum
recalculate feature.position using adjusted angle
-- Ring wall check: 8 points at 0.35m radius --
for i in 0..7:
angle = i * 45 deg
checkPoint = feature.position + 0.35m in that direction
if SLAM.isPositionOccupied(checkPoint): return null
-- All checks passed: create the node --
node = graph.createNode(feature, timestamp)
featureDetector.registerKnownFeature(feature.position)
publish node to network
return node
Note No SLAM node map is created here. The robot has not physically visited this position. SLAM data is only captured when the robot arrives at a node (in doArriving).
+
checkLineOfSight(scan, pose, toX, toY) → { clear, bestAngle } +/-20 deg search for NODE PLACEMENT only — finds best wall clearance angle
Used for NODE PLACEMENT only This function searches a +/-20 deg window to find the angle that maximizes clearance from walls on both sides. It is NOT used for edge creation. Edges use hasDirectLineOfSight (direct ray, no search).
angleToTarget = atan2(dy, dx) - pose.theta
searchHalf = +/-20 deg
-- Collect all ray indices within the +/-20 deg window --
windowIndices = rays where abs(angle - angleToTarget) ≤ searchHalf
if none found: return { clear: false }
-- Score each ray that reaches the target distance --
for each ray in window:
skip if ray range < target distance -- hits a wall before target
-- Measure wall clearance on both sides --
leftWallDist = count clear rays scanning leftward from this ray
-- Rays outside window = wall (distance 0)
-- Rays with range < 50% of target distance = wall
rightWallDist = same, scanning rightward
score = min(leftWallDist, rightWallDist)
-- Maximize the tightest side (center of corridor)
return { clear: bestScore ≥ 0, bestAngle: ray angle + pose.theta }
+
hasDirectLineOfSight(scan, pose, toX, toY, dist) → boolean Single direct ray for EDGE CREATION — no angular search
Used for EDGE CREATION only No +/-20 deg search. The edge is a straight line — if the direct ray cannot see the target, the straight-line edge would pass through a wall.
if distance < 0.1m: return true
if distance > scan.max_range: return false
angleToTarget = atan2(dy, dx) - pose.theta
-- Find the single closest ray to the target angle --
bestIdx = ray with smallest angular difference to angleToTarget
return scan.ranges[bestIdx] ≥ target distance
+
detectSidePassages(scan, pose) Find perpendicular openings (wall-to-free transitions) in corridors
-- Only check every 0.5m of travel --
if moved < 0.5m since last check: return
-- Check corridor is wide enough for a junction node --
corridorWidth = leftWall + rightWall (from LiDAR perpendicular rays)
if corridorWidth < 1.0m: return -- too narrow
for each ray pair in scan:
-- Detect short-to-long transition (wall-to-opening) --
if nextRange - thisRange > 1.5m (jump threshold):
skip if wall distance < 0.3m or > 80% of scan range
skip if not perpendicular to heading (must be pi/4 to 3pi/4)
skip if opening range < 2.0m
-- Case 1: Existing node visible through opening --
if a node is visible within 0.3 rad of opening angle:
create edge from anchor to existing node (if not already connected)
-- Case 2: No node visible -- create junction + target --
else:
junction = create node at robot position (on the corridor path)
-- Junction must have edge to anchor node (atomic) --
if junction edge fails: remove junction
target = create node at 75% of visible range into opening
-- Target must have edge to junction (atomic) --
if target edge fails: remove target
skip ahead 10 rays -- avoid double-detecting same opening
+
analyzeCorridorOnArrival(timestamp) Retroactive junction detection from corridor scan log
-- After travel completes, analyze the corridor scan samples --
-- collected every 0.3m during TRAVELING phase --
departureNode = nearest node to first sample (node A)
arrivalNode = currentNode (node B, set by completeTravel)
travelAngle = atan2(B.y - A.y, B.x - A.x)
perpLeft = travelAngle + 90 deg
perpRight = travelAngle - 90 deg
-- Compute perpendicular ranges for each sample --
for each corridor sample:
leftRange = nearest ray within 15 deg cone of perpLeft
rightRange = nearest ray within 15 deg cone of perpRight
-- Detect jumps between consecutive samples --
for each consecutive pair (prev, curr):
if curr.leftRange - prev.leftRange > 1.5m:
and next sample also confirms the opening (width > 0.5m):
record left passage at curr.pose
-- Same check for right side --
-- Deduplicate passages within 1.0m of each other --
for each detected passage:
-- Project passage position onto the A-to-B line --
t = clamp(dot product projection, 0.05, 0.95)
junctionPos = A + t * (B - A)
if near existing node: use it as junction, just create branch edge
else: create junction node on A-B line
-- Create target node into the passage at 75% of visible range --
targetPos = junctionPos + 75% * range * direction
if no existing node near target and position is free:
create target node + edge to junction (atomic)
-- Split the original A-to-B edge into a chain --
if junctions were created and original traveled edge exists:
sort junctions by distance from A
remove original A-B edge
build chain: A → J1 → J2 → ... → B
for each link in chain:
create traveled edge with measured distance
-- Clean up: remove orphaned junction nodes with no edges --
clear corridorScanLog
+
completeTravel(scan, pose) Finalize travel: mark edge traveled, update current node
-- Mark the active edge as traveled with measured data --
if no arrival node exists:
create a new node at current position via createNode
if creation fails: cancel edge, return
complete edge map (corridor data) under graph edge ID
if activeEdge exists:
measuredBearing = atan2(pose.y - startPose.y, pose.x - startPose.x)
graph.markEdgeTraveled(activeEdge, robotId, accumulatedDistance, measuredBearing)
else:
create a new traveled edge from departure to arrival
currentNodeId = arrival node
clear target, activeEdge
+
checkWallStop(scan, pose, target) → boolean Detect when robot is stuck against a wall mid-travel
if ticks in travel < 15: return false -- too early to judge
-- Check progress: has robot moved enough? --
distFromStart = distance(pose, travelStartPose)
expectedProgress = ticksInTravel * 0.03
if distFromStart > expectedProgress: return false -- making progress
-- Check forward clearance --
minForward = minimum range within +/-30 deg of heading
if minForward > 0.5m: return false -- path ahead is clear
-- Wall stop triggered --
create dead-end node at current position via createNode
if clearance check rejects: fallback to createNodeAtPosition
create traveled edge from departure node to wall-stop node
set currentNode = wall-stop node
transition to ARRIVING
return true

chooseExplorationEdge(nodeId) → { edge, reason } | null 4-tier exploration priority for choosing next edge
edges = all edges connected to nodeId
if no edges: return null
0
BFS to unexplored — Find any unexplored node in the graph. BFS from current node, tracking parent edges. Return the first edge on the shortest path to the nearest unexplored node.
1
Untraveled edges — Filter for edges that have never been physically traversed. Pick the one with smallest distance.
2
Most unmapped neighbor — For each adjacent node, count its untraveled edges. Pick the neighbor with the highest count.
3
Random — Pick a random connected edge as last resort.
+
findPath(fromId, toId) → [{ nodeId, edgeId }] | null BFS shortest path, skips blocked edges
-- Standard BFS shortest path by hop count --
queue = [fromId]
visited = { fromId }
parent = {} -- maps nodeId to { fromNodeId, edgeId }
while queue not empty:
current = dequeue
for each edge from current:
skip if edge status is Blocked
neighbor = other end of edge
skip if already visited
record parent[neighbor] = { current, edge.id }
if neighbor == toId: reconstruct path, return
enqueue neighbor
return null -- no path found
+
revalidateEdgesFromNode(nodeId, visibleNodeIds, timestamp) Edge health check based on current LiDAR visibility
for each edge connected to nodeId:
otherNode = the node at the other end
if otherNode is visible (in visibleNodeIds):
refresh edge timestamp
increase confidence by +0.05
if was Blocked: change status to Open
else if edge was traveled or Open (now invisible):
-- Previously confirmed path is now blocked --
mark status = Blocked
reduce confidence by 30% (floor at 0.15)
-- Edge is KEPT, not deleted --
else (untraveled, invisible):
-- Speculative edge no longer visible --
reduce confidence by 50%
+
pruneDeadEntities() → { prunedNodeIds, prunedEdgeIds, disconnections } Remove dead-tier entities while protecting confirmed topology
Pruning Rules — NEVER Violated NEVER prune traveled edges — they represent real paths the robot has walked. Mark as Blocked instead.
NEVER prune blocked edges — they are information about the topology (a connection that may reopen).
NEVER prune explored nodes — they represent real places the robot has been.
-- Step 1: Process dead-tier edges --
for each edge where tier == Dead:
if edge.traveled:
DO NOT prune — set status = Blocked, confidence = 0.10, tier = Candidate
if edge.status == Blocked:
DO NOT prune — set confidence = 0.10, tier = Candidate
otherwise (untraveled, not blocked):
remove edge from graph -- speculative connection that decayed
-- Step 2: Find orphaned dead-tier nodes --
for each node where tier == Dead:
if node.explored: DO NOT prune
if node has no remaining edges:
remove node from graph
-- Step 3: Check for graph disconnection --
if edges were pruned: run connected components check
if graph split: flag as disconnection event (do not auto-fix)

Feature Detector — LiDAR Scan Analysis

src/robot/feature-detection/feature-detector.ts
+
detectFromScan(scan, pose) → DetectedFeature[] Full 360-degree LiDAR analysis, returns navigable positions
-- Step 1: Classify the robot's current local position --
openDirections = findOpenDirections(scan)
if exits ≥ 3: classify as Junction
if exits ≤ 1: classify as DeadEnd
if exits == 2 and angle between them < 108 deg: classify as Corner
-- Step 2: Place nodes along every open direction --
for each open direction:
if ray hits max range (95%): place node at 75% of max range
else: place node at range - 0.5m (at least 1.5m away)
skip if center ray does not reach that distance
create feature at computed position
-- Step 3: Detect side openings (range discontinuities) --
for each ray pair with short-to-long jump > threshold:
skip if wall too close (<1.0m) or too far (>90% range)
place Junction node at opening distance along the long ray
-- Deduplicate and filter --
remove features within 1.0m of known features (keep higher confidence)
remove features within 1.0m of each other in this batch
return filtered features
+
findOpenDirections(scan) → OpenDirection[] Group long-range rays into corridor directions
-- Threshold: rays reaching beyond 1.5m indicate open space --
threshold = 1.5m
-- Group consecutive long rays (minimum 3 per group) --
for each ray in scan:
if range > threshold: add to current group
else: close group (if ≥ 3 rays), start new one
-- Wrap-around merge (first and last group may be contiguous) --
if first and last groups' angles are within 0.2 rad: merge them
-- Split wide groups at range peaks --
for each group:
if angular width > 90 deg and > 20 rays:
findRangePeaks(group) -- each peak = one corridor direction
return each group as { centerAngle, maxRange, angularWidth }
+
findRangePeaks(group) → subGroups[] Split wide ray groups at local range maxima
-- Smooth range values with window = 3 --
for each ray: smoothed[i] = average of neighbors within +/-3
-- Find local maxima (peaks) --
for each smoothed value (skip first/last 5):
if value > all 3 neighbors on each side:
and value > 2.0m:
and at least 15 rays from previous peak:
record as peak
if no peaks found:
-- Fallback to cardinal directions (N, E, S, W) --
for each cardinal angle: find nearest ray, extract sub-group
otherwise:
for each peak: extract sub-group of +/-15 rays around peak center
return sub-groups

driveToward(target, pose, scan, timestamp) → MotorCommand Reactive navigation with wall avoidance and corridor centering
targetAngle = angle from robot to target (relative to heading)
safetyMargin = robot_radius + 0.15m
-- EMERGENCY: something within safety margin --
nearestAll = minimum range in full 180 deg forward hemisphere
if nearestAll < safetyMargin:
find angle of closest wall
drive directly AWAY from closest wall
return { linear: 0.3, angular: awayAngle * 3.0 }
-- Check clearance toward target --
targetClearance = min range in +/-10 deg cone toward target
if targetClearance > 1.0m:
steerAngle = targetAngle -- go direct
else:
steerAngle = findBestOpenDirection(scan, targetAngle)
-- Speed proportional to clearance --
aheadClear = min range in +/-15 deg of steer direction
speedFraction = clamp((aheadClear - safetyMargin) / 2.0, 0.1, 1.0)
command = steer toward steerAngle, scale speed by speedFraction
-- Side wall avoidance (corridor centering) --
leftMin = min range at +90 deg
rightMin = min range at -90 deg
if min(leftMin, rightMin) < 0.8m:
push angular velocity toward the side with more room
if very close (< safetyMargin): reduce speed to 20%
return command
+
findBestOpenDirection(scan, targetAngle) → { angle, range } Sample 36 directions, pick closest to target with clearance
-- Sample 36 evenly spaced directions (every 10 deg) --
for i in 0..35:
sampleAngle = -180 deg + i * 10 deg
clearance = min range in +/-8 deg cone around sampleAngle
if clearance > ahead_clear_threshold (0.8m):
record as candidate with angleDiff from targetAngle
if no candidates with enough clearance:
pick the direction with maximum range (emergency escape)
otherwise:
pick the candidate closest to targetAngle
return { angle, range }
